The chip sits in the column header for a table and next to the label for a single value. One chip per number.

4. Day slider: keyboard and screen reader

Try it. It is one tab stop with the slider role.

A screen reader says:

  • ← → move one day. Home is today, End is day 14. Dragging and clicking the track do the same.
  • The spoken value is the day and its date, not a bare number.
  • Moving the slider makes no request. Numbers that change with the day sit in a polite live region, so they are read after the value, once.
  • The focus ring is always visible. Tick labels sit exactly under their day.

5. Tables: keyboard and screen reader

  • Real table markup: column headers with scope, the source chip inside the header so it is read with the column name.
  • A row that opens something is one tab stop and opens with Enter. The row's first cell is its name.
  • Tags are read as words: "60 to 110, stale". "Too few sales to predict" is text in the cell, not an empty cell.
  • Charts have a "Show as table" switch with the same numbers.
  • Filters are labelled dropdowns. Changing one keeps focus on it. An empty result says "No products match these filters."
